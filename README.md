# mend

One patch tool for every AI edit format: a command-line tool that applies
AI-written edits — unified diffs (often with wrong line numbers),
SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of files,
exactly as SPEC.md specifies. All files change, or none do.
